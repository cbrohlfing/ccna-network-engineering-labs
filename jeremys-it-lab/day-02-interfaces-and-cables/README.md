## 1. Learning Objectives

- Identify common Ethernet cables and connectors.
- Understand the differences between copper and fiber-optic connections.
- Recognize common Cisco network interfaces.
- Select appropriate cables for network connections.
- Understand basic Ethernet interface characteristics.

## 2. Lab Activity

Completed the guided Packet Tracer cabling exercise accompanying Jeremy's IT Lab Day 02.

## 3. Concepts Reviewed

### Copper Ethernet

- Twisted-pair Ethernet cabling
- RJ-45 connectors
- Straight-through and crossover cable concepts
- Ethernet interface speeds and distance limitations

### Fiber-Optic Ethernet

- Single-mode and multimode fiber
- Optical transceivers
- Fiber applications and distance considerations

### Network Interfaces

- Cisco interface naming conventions
- Ethernet interface identification
- Physical connectivity and interface compatibility

## 5. Lessons Learned

Physical connectivity is the foundation of network communication. Selecting compatible cables, interfaces, and transceivers is essential before configuring higher-layer network services.
