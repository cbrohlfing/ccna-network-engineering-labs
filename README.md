# CCNA Network Engineering Portfolio

**Hands-on networking projects, Cisco Packet Tracer labs, technical documentation, and troubleshooting exercises developed during preparation for the Cisco CCNA 200-301 certification.**

This repository documents my progression in network engineering through independent network design projects, guided technical exercises, and practical application of networking fundamentals.

The goal is to demonstrate not only how networks are configured, but also how they are designed, verified, troubleshot, and documented.

## Featured Project — Project Snowden

**Project Snowden** is an evolving, multi-site enterprise network developed independently to build practical network engineering skills.

The project begins with basic two-site IPv4 connectivity and progressively introduces more advanced networking technologies.

Each lab builds upon previous infrastructure, providing opportunities to practice network design, Cisco IOS configuration, routing, switching, verification, and troubleshooting.

- [Lab 001 — Two-Site Network Connectivity](project-snowden/lab-001-two-site-connectivity/README.md) — IPv4 addressing, static routing, Ethernet switching, ARP, ICMP, and traceroute.

## Documentation Standards

All completed lab reports follow the **Network Engineering Lab Report Standard v1.0**.

The standard provides a consistent technical documentation structure:

1. Lab Overview
2. Learning Objectives
3. Network Topology
4. Addressing and Design
5. Implementation
6. Verification and Testing
7. Troubleshooting
8. Key Concepts and Lessons Learned
9. Lab Outcome
10. Supporting Files and References

Lab reports distinguish between verified results, configuration summaries, conceptual explanations, and planned future work.

Sections that do not apply to a particular exercise are identified accordingly.
