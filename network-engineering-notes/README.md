# Network Engineering Notes

A growing collection of technical notes, command references, and troubleshooting procedures developed during my CCNA studies and hands-on network engineering labs.

## Purpose

This section serves as a reference library for networking concepts and Cisco IOS operations encountered throughout my studies.

Unlike the lab reports, which document specific implementations and test results, these notes focus on reusable technical knowledge.

## Planned Topics

- **Cisco IOS Command Reference** — Configuration, verification, and troubleshooting commands
- **IPv4 Addressing and Subnetting** — Address allocation, subnet calculations, and CIDR notation
- **Ethernet and Switching** — MAC addressing, ARP, VLANs, and trunking
- **Routing Fundamentals** — Routing tables, static routes, and dynamic routing protocols
- **Network Troubleshooting** — Diagnostic commands and systematic troubleshooting methods
- **Network Protocols** — TCP/IP, ICMP, DNS, DHCP, and other networking protocols

## Documentation Approach

Notes will be developed and expanded as concepts are studied and applied in practical lab environments.

Where applicable, examples will reference completed labs from Project Snowden or Jeremy's IT Lab.

Technical notes will distinguish between conceptual explanations, example configurations, and commands verified during actual lab exercises.
